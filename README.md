# Grocery Blueprint 🇮🇱
**Israeli Meal Planning & Supermarket Cart Optimizer**

Grocery Blueprint is a 100% private, client-side web application designed for meal planning and grocery cart optimization across Israel's major supermarket chains (Rami Levy, Osher Ad, Shufersal Deal, Yohananof, Victory, and Carrefour).

## Features
- **115+ Everyday Kosher Dishes**: Dinner recipes, boxed prep lunches, and quick breakfasts.
- **2-Night Batch Cooking Mode**: Cook once on Sunday and Tuesday, enjoy effortless leftovers on Monday and Wednesday.
- **Multi-Day Repetition**: Assign meal prep lunches or breakfasts across 2, 3, or all 5 weekdays in 1 click.
- **Custom Meal Creator with Live Auto-Pricing**: Build your own recipes; ingredient costs total automatically based on live Israeli market prices.
- **Israeli Kitchen Pantry (50 Staples)**: Deduct pantry staples you already have in your cupboards (olive oil, za'atar, tahini, spices, grains) to calculate your exact supermarket spend.
- **Direct Online Cart Export**: Generate copyable Smart Lists for Rami Levy & Shufersal Online, plus live search links for every item.
- **WhatsApp Export**: Formatted Hebrew supermarket shopping list ready to send via WhatsApp.

## How to Run
1. Double-click `index.html` or `grocery_blueprint.html` to open it in any web browser.
2. No installation, server, or database required — all data is saved securely in your browser's LocalStorage.
3. You can also drag and drop this folder onto [Netlify Drop](https://app.netlify.com/drop) or host on GitHub Pages / Cloudflare Pages for personal access from any device.
